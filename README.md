## 🚀 Getting Started

### 🔧 Clone the Repository
```bash
git clone https://github.com/ActuallyMadhav/SC2001-Algorithm-Analysis-Lab.git
cd SC2001-Algorithm-Analysis-Lab
```

### 🛠️ Prerequisites
- C++ compiler (e.g., `g++`)
- Python 3.x
- Matplotlib (for Lab2 visualisation)

### ⚙️ Running C++ Code
Navigate to the appropriate lab folder and compile:
```bash
cd Lab1/Cpp\ Solution
g++ lab1Main.cpp -o lab1
./lab1
```

### 🐍 Running Python Code
Navigate to the Python solution folder and execute:
```bash
cd Lab2/Python\ Solution
python3 visualisation.py
```

## 📊 Performance Analysis

Each lab includes:
- Theoretical time complexity derivation
- Empirical benchmarking (key comparisons, CPU time)
- Trade-off discussions and optimization strategies
